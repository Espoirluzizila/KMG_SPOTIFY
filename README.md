## Fonctionnement audio

Le lecteur prend en charge la lecture, la pause, le titre suivant, le titre précédent, la barre de progression, le volume et les états de chargement.

## Déploiement sur Vercel

1. Placer tous les fichiers à la racine du dépôt.
2. Importer le dépôt dans Vercel.
3. Utiliser le preset **Other** si Vercel demande un framework.
4. Aucun build command n'est nécessaire.
5. Déployer.

## Développement local

Ouvrir `index.html` dans un navigateur moderne ou lancer :

```bash
python -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.
